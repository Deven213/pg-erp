PG ERP - interactive mobile wireframe

How to open: unzip, then double-click index.html (Chrome, Edge or Firefox).
No install or server needed. Internet is only used for fonts.

Left panel: switch Owner app / Resident app / Super Admin / Login and jump to any screen.
Right panel: what the screen does, things to try, and buttons to preview loading/empty/error/offline states.

Files: data.js (sample data), core.js (router + UI components), auth.js, owner.js, finance.js, ops.js, resident.js, admin.js (screens).
